# Asignación #11 – Transformer, GPT y Webapp con Streamlit + Gemini

Este proyecto forma parte de la asignatura **Inteligencia Artificial y Creatividad**.  
Incluye dos partes principales: un ensayo reflexivo y una aplicación web interactiva desarrollada con Streamlit y la API de Gemini.

---

## 1. Ensayo sobre la arquitectura Transformer y el modelo GPT

Ensayo de 2 cuartillas donde reflexiono sobre:

- La arquitectura Transformer presentada en *Attention is All You Need* (2017).
- El paper *Improving Language Understanding by Generative Pre-Training*.
- Cómo estas tecnologías cambiaron la forma en la que interactuamos con la IA.
- Implicaciones culturales, creativas y personales.

---

## 2. Webapp en Streamlit Cloud + Gemini

Aplicación web que permite:

- Enviar prompts personalizados.
- Recibir respuestas generadas por **Gemini 1.5 Flash**.
- Elegir un “modo de respuesta” (claro, académico o creativo).
- Usar una interfaz con estilo y CSS personalizado.

### Tecnologías utilizadas
- Python 3.10  
- Streamlit  
- Google Generative AI (Gemini)  
- dotenv para variables de entorno  
- HTML/CSS embebido
